# docs — журнал решений

Файл на решение, датированный, **только дописываемый**. Здесь лежит то, чего
нельзя получить чтением кода: почему выбрано так, что рассматривали и что
отвергли. Всё, что описывает «как сейчас», живёт в другом месте — нормы в
`CLAUDE.md` и `.claude/rules/`, значения в самом коде, дизайн-система в
`DESIGN.md`.

Правила ведения:

- **Имя файла:** `ГГГГ-ММ-ДД-краткий-слаг.md`, дата — день решения.
- **Одно решение — один файл.** Уточнения того же решения дописываются в его
  файл, даже если пришли позже.
- **Записи не переписываются.** Устаревшая запись остаётся: она фиксирует, что
  на тот момент считали верным. Изменение решения — новая запись со ссылкой на
  старую.
- **Намерение сюда не кладут.** Спека живёт отдельно, пока не реализована;
  после реализации она схлопывается в запись и удаляется.
- Бэклог тоже не журнал. Если нужен снимок открытых вопросов — это датированная
  запись-снимок, которая дальше не правится.
